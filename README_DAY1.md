# Day 1 package - data foundation

## What is in here
| Path | Purpose |
| --- | --- |
| `pipeline/ingest_species.py` | Splits every `value [Source: url]` cell, normalizes values, ranks sources, writes the species tables and an issue report |
| `pipeline/rebuild_site_grid.py` | One row per grid cell, real slope from elevation, land-use zone and legal flag, drops the fake slope and random pH |
| `pipeline/qa_day1.py` | 37 automatic checks (34 pass, 3 expected warnings) on the outputs |
| `data/raw/` | Your two input CSVs (read-only) |
| `data/processed/` | Generated outputs (CSV + `optimizing_survival.db`) - regenerate any time |
| `data/config/purpose_weights.csv` | PROVISIONAL purpose weights (each purpose sums to 1.00) |
| `CLAUDE.md`, `docs/FOUR_DAY_PLAN.md` | Context and the scoped plan for Claude Code |

## Run it (from the repo root)
```
pip install -r requirements-day1.txt
python pipeline/ingest_species.py --input data/raw/species_directsource.csv --sources data/raw/sources_list.csv --out data/processed
python pipeline/rebuild_site_grid.py --input backend/Working_Points.csv --landuse data/LandUses.shp --out data/processed
python pipeline/qa_day1.py --out data/processed
```
Expected: 45 species; 2,348 cited cells (ranks: 258 Rank 1, 327 Rank 2, 1,577 Rank 3, 152 Rank 4, 34 file citations);
8,088 grid cells; slope median about 20%; 6,251 points in legal zones; QA = 34 passed, 3 warnings, 0 failed.

## What Day 1 found (details in `ingest_report.csv`, `grid_report.txt`)
- 34 Batikuling cells cite a PDF that was never provided. Treat them as unverified until the file is added.
- 30 cells cite URLs outside your SOURCES list; 20 cells use a non-standard citation format; 1 URL is missing `https:`.
- The endangered scheme (DENR vs IUCN) is not named in 44 of 45 species.
- 6 species list no Type I climate preference (Katmon, Batikuling, White Lauan, Red Lauan, Bagtikan, Apitong).
- Soil text maps to texture classes provisionally: review `soil_map_review.csv`. Root types (21) and urban tags (25) need review in `tag_maps_*.csv`.
- Grid: 8,255 rows collapse to 8,088 cells; 1,279 cells (16%) fall outside the zoning polygons; 22% of cells have a one-axis slope only.

## Move the work into Claude Code (VS Code)
Claude Code cannot see this chat, so the repo itself carries the context.
1. Download `optimizing-survival-day1.zip` from this chat and unzip it **into your repo root** (it adds `pipeline/`, `docs/`, `data/raw`, `data/processed`, `data/config`, `CLAUDE.md`, `requirements-day1.txt`; nothing existing is overwritten).
2. Create a branch (for example `day1-data`) and commit. Optional: add `data/processed/*.db` to `.gitignore` (it is regenerated by the scripts).
3. Open the repo folder in VS Code and open the Claude Code panel. It reads `CLAUDE.md` from the project root automatically at the start of a session.
4. Paste this first message:
   > Read CLAUDE.md and docs/FOUR_DAY_PLAN.md. Run the three commands in README_DAY1.md and tell me if anything fails in my environment (fix it without changing the output meaning). Then start Day 2 task 1 (`pipeline/score_sites.py`) following the acceptance criteria, and run the QA/tests before you finish.
5. Optional: in the master plan doc, export it as Markdown and save it as `docs/MASTER_PLAN.md` so Claude Code has the full design.
6. Work split: Claude Code edits and runs things in the repo; bring results back here for review (paste the QA output or the diff summary) or to read new sources.

## Limits (state these in the thesis)
RF labels derive from rules; weights are provisional; pH is not scored; slope comes from ~100 m cells; soil texture mapping is unverified.
